# Gmind 编辑器 UI 重设计 · 三方向工作稿

日期：2026-10-21 ｜ 范围：仅编辑器主界面（桌面 web，1440×900）｜ 约束：完全自由探索，跳出企微对标框架

## 设计 Spec（三方向共用输入，只写"要说什么"）

**项目**：Gmind 在线协作脑图——浏览器端、协作为先的脑图工具，一期已收官（M0~M6）。
**受众与场景**：国内团队用户，日常高频使用的生产力工具；一坐就是半小时以上的深度编辑场景。
**核心信息 / 功能清单**（界面必须安放，不许漏）：
- 身份区：返回、文档标题、星标、保存状态（已保存 HH:MM / 离线编辑中）
- 视图切换：脑图 / 表格
- 编辑操作：撤销、重做、格式刷；插入上级/子级/同级主题；添加概要
- 检查器：格式面板（富内容/图片四槽位）、任务面板（负责人/9档进度/预期日期/逾期）
- 画布控制：结构切换（脑图/树/组织图）、12 套主题、简洁模式
- 导出：XMind、PNG/JPG（1/2/3x、透明背景）
- 协作：成员面板＋在线数角标、远端光标、评论（线程/定位/角标）、通知
- 历史：版本快照（预览/恢复）、文档动态、查找替换、快捷键帮助
- 底栏：节点计数、定位中心、适应画布、缩放档位、全屏

**演示内容**：脑图画「Gmind 产品功能地图」本身——中心节点 Gmind，六条主枝：协同编辑 / 编辑内核 / 任务管理 / 文件与分享 / 团队与历史 / 个性化（均取自真实功能，不编造）。
**情感基调**：专业但不做作；让人愿意每天打开的工具，不是演示厅里的展品。
**输出格式**：单文件 HTML，1440×900 桌面优先；交互（tab、面板开合、右键菜单）要真能点。
**已知约束**：T0 素材档（无生成图）；主角素材=脑图本身（程序化 SVG，数据即图像）；正文 ≥14px、标签 ≥12px、对比度 ≥4.5:1。
**form 五问**：叙事角色=长时间陪伴的工作台；观众距离=手臂距离操作界面；视觉温度=各方向自定；容量=极高（9 组功能+面板群）；视觉母题=脑图的"分枝"——从中心长出去的结构，这是这个题材才有的形。

## 六张方向卡

### C1 · 最佳设计师（克制）——Oliver Reichenstein / iA Inc.
- 逻辑与来源：iA Writer 之父，"写作工具应当消失"哲学的代表；编辑器 UI 克制派的极致。
- 借的是什么：信息层级的减法——同一时刻只露一层 chrome；字体即界面（字号/字重/灰度承担全部层级）；长灰阶无彩色，唯一颜色留给"内容本身"（脑图分枝色）。
- 主角素材：脑图 SVG 是唯一色彩来源；chrome 全灰白。
- 骨架：顶部一条 36px 极窄栏（只有标题/保存态/成员），其余全部收进悬浮右键与指令面板（⌘K）；右侧检查器按需滑出。
- 胆量花在哪：敢把 9 组工具栏收到一个 ⌘K——赌高频用户靠键盘。
- form 来自内容的哪里：脑图需要专注，chrome 的消失速度=心流的进入速度。

### C2 · 最佳设计师（大胆）——Studio Dumbar
- 逻辑与来源：荷兰 Studio Dumbar，大胆色彩系统＋动态网格，为机构做"有能量的秩序"。
- 借的是什么：功能分区=色块分区（每组功能一个高饱和识别色，颜色即寻址）；大胆而精确的网格；图形化的微状态（保存态/在线数做成图形信号而不是小灰字）。
- 主角素材：彩色功能区块＋脑图 SVG；色彩来自功能而非装饰。
- 骨架：顶部色带式工具栏（每组功能一个色块 chip 区），左侧细工具轨，底部状态条图形化。
- 胆量花在哪：工具栏不再是灰色一排，是一排"彩色按钮墙"——像调音台。
- form 来自内容的哪里：脑图本身是彩色分枝，工具彩块与画布里的分枝色互为呼应。

### C3 · 现实参照——Whimsical（亲眼看：refs/whimsical.png）
- 逻辑与来源：同媒介（web 脑图/白板工具），截图确认其编辑器 chrome。
- 借的是什么：左侧 48px 深色细工具轨（纵向 icon 栈）；顶部面包屑标题栏＋右侧头像簇＋ Share 主按钮；脑图每条主枝一个颜色（magenta/orange/teal），连线彩色渐变；画布大留白。
- 主角素材：彩色分枝脑图；chrome 退到细轨和细栏。
- 骨架：左细轨＋顶细栏＋全画布，右侧面板从顶栏触发滑出。
- 胆量花在哪：把"功能密度"藏进一条 48px 轨道，其余全是画布。
- form 来自内容的哪里：分枝色是脑图工具独有的资产，让它成为界面里最显眼的东西。

### C4 · 现实参照——MindNode（亲眼看：refs/mindnode.png，Apple Editors' Choice）
- 逻辑与来源：同媒介（脑图工具，Editors' Choice），截图确认其气质。
- 借的是什么：圆润胶囊节点＋有机曲线连线＋柔和 pastel 分枝色；"Your Brain Doesn't Think in Straight Lines"的温度——工具可以亲切；大圆角、软阴影、轻拟物层级。
- 主角素材：圆润 pastel 脑图；圆角软阴影面板。
- 骨架：顶部居中浮动胶囊工具条（毛玻璃），四角悬浮控件（左上标题卡、右上成员卡、右下缩放卡），无边界画布。
- 胆量花在哪：编辑器没有一条直线边框，全部悬浮胶囊。
- form 来自内容的哪里：脑图的曲线是"思考的曲线"，chrome 也用同一种曲线语言。

### C5 · 秒数轮盘（web #2）——新粗野主义撞色信息流（The Verge 系）
- 逻辑与来源：抽中网页分区 #2，已看样张 sheet/web/02。
- 借的是什么：2-3px 粗黑描边卡片＋4px 硬偏移投影；高饱和色块（电紫/亮黄/品红/薄荷）做功能分区； boxed label（细框小标签）；近乎无圆角；hover 撞色翻转。
- 主角素材：黑描边白节点脑图（连线黑色，节点 hover 撞黄）；工具面板是色块拼贴。
- 骨架：杂志拼贴式——标题卡（描边大字）压左上，工具卡分区撞色块，底栏黑底白字通栏。
- 胆量花在哪：把生产力工具做成一张可操作的"zine"，保存状态用亮黄块砸在脸上。
- form 来自内容的哪里：脑图是想法的黑板，黑板可以贴满彩色便签。

### C6 · 秒数轮盘（east #6）——香港街招与招牌
- 逻辑与来源：抽中东亚分区 #6，已看样张 sheet/east/06。
- 借的是什么：深色"墙面"画布＋层层叠放的招牌式面板（高饱和纯色块＋奶白描边＋外发光）；竖排中文标签；密排信息但每块归属明确。
- 主角素材：夜色画布上发光分枝的脑图；功能面板做成"挂牌"。
- 骨架：暗底画布，工具是几块可拖叠放的"招牌"卡，竖排标签栏贴左缘。
- 胆量花在哪：整版做成夜景墙面（三版里唯一的"道具化"名额，用它）。
- form 来自内容的哪里：脑图在暗处发光，像想法在夜里亮起来；中文竖排是东亚脑图工具少有的仪式
感。
