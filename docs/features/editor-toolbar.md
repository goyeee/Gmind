# 编辑器顶部栏

## ① 这是什么

编辑器最上方的一行工具栏：左侧是 Gmind 品牌、文件名、星标和保存状态，中间是脑图/表格与真实编辑工具，右侧是协作成员和分享。点 Gmind 标志返回工作台；点文件名旁铅笔修改文件名；点成员头像打开“协作成员”；点分享打开四页签弹窗（`apps/web/src/pages/EditorPage.tsx:4095-4165`、`:4500-4535`）。

## ② 规则（逐条）

1. **品牌与返回**：最左使用 Share2 连线标志和“Gmind”，点击仍执行原来的返回工作台，不新增首页（`apps/web/src/pages/EditorPage.tsx:4099-4113`）。
2. **桌面布局**：顶栏高 52px，成员与分享按钮高 40px，成员头像 28px。1512、1440、1280 均保持单行，不使用中部横向滚动（`apps/web/src/pages/editor.css:60-68`、`:691-710`、`:1165-1174`、`:1285-1305`）。
3. **弹窗改名**：点铅笔打开 420px 弹窗，原标题自动全选；取消不写，trim 后为空不能确定，Enter 或“确定”提交。确认后才写入文档并走既有防抖保存，不再每敲一个字就保存（`apps/web/src/editor/RenameFileDialog.tsx:5-84`；`apps/web/src/pages/EditorPage.tsx:5043-5054`）。
4. **改名权限**：创建者和可编辑成员可改名；可评论、仅查看用户没有铅笔入口，直接调用 PATCH 也返回 404。工作台文件列表携带当前用户真实角色，卡片和列表菜单也只向创建者/可编辑成员显示“重命名”（`apps/server/src/files/files.service.ts:737-755`；`apps/web/src/pages/WorkspacePage.tsx:178-180`、`:244-248`、`:328-333`）。
5. **成员总人数**：顶部数字是真实协作者总数，不是在线数。任务候选目录仍保留历史负责人，但顶部目录不把仅被任务指派的人算入（`apps/web/src/editor/TaskFields.tsx:126-196`；`apps/web/src/pages/EditorPage.tsx:661-677`）。
6. **在线与离线**：本人优先，其余在线成员优先、同组按昵称稳定排序；在线带绿点，离线置灰。成员关闭页面后在线数下降，但总人数不变（`apps/web/src/editor/collab.ts:165-190`）。
7. **头像叠加**：最多直接显示 4 人；恰好 5 人全部显示，6 人起显示 4 个头像和“+N”（`apps/web/src/editor/collab.ts:173-190`）。邀请或移除成功后，弹窗名单与顶部总人数同步刷新（`apps/web/src/editor/MemberPanel.tsx:21-65`；`apps/web/src/editor/ShareDialog.tsx:210-217`）。
8. **导出去重**：顶部不再显示导出按钮或旧导出菜单；统一从“分享 → 导出”进入。图片行支持 JPG 1×/2×/3×，默认 2×，其他四种格式不变（`apps/web/src/editor/ShareDialog.tsx:175-184`、`:262-278`）。
9. **更多与既有入口**：版本历史、评论、快捷键在“更多”中；待办、动态、查找保持原位置和功能，本轮没有合并待办汇总与动态（`apps/web/src/pages/EditorPage.tsx:4317-4326`、`:4423-4490`）。
10. **手机与窄窗口**：900px 及以下使用简化画布，不装配节点编辑工具；文件创建者和可编辑成员仍有铅笔改名，所有已登录协作者保留分享与成员入口，评论和保存状态照常可用（`apps/web/src/editor/useIsMobileViewport.ts:3-30`；`apps/web/src/pages/EditorPage.tsx:4112-4150`；`apps/web/src/pages/editor.css:1308-1318`）。

## ③ 特殊情况

- **中文输入**：拼音组合期间按 Enter 不提交；组合结束后再按 Enter 或点确定才保存（`apps/web/src/editor/RenameFileDialog.tsx:66-75`）。
- **空名与取消**：全空格禁用确定；取消、Escape 或点遮罩不修改标题。弹窗支持 Tab 焦点循环，关闭后焦点回铅笔（`apps/web/src/editor/RenameFileDialog.tsx:19-56`）。
- **长文件名**：桌面标题单行省略，完整名称可在悬停提示和改名弹窗中查看；1280 保留 120px，不恢复此前 84px 的窄输入框（`apps/web/src/pages/editor.css:183-190`、`:1303-1306`）。
- **窄屏空间**：1366px 及以下隐藏标题组保存时间，保存逻辑不停止；较宽桌面恢复显示。版本历史在“更多”中仍可打开原面板。
- **移除成员**：删除接口返回 204 空响应；前端成功后刷新名单。此前 200 空响应会被误当 JSON 解析失败，导致删除成功却不刷新（`apps/server/src/files/files.controller.ts:166-172`）。

## ④ 待需求方确认

1. **版本历史在所有桌面宽度统一收进“更多”**：实施时为遵循原型并避免断点跳动这样处理，需求方批准了大方向，但未单独确认所有宽度都多一次点击。
2. **1366px 及以下隐藏保存时间**：这是为保持单行回收空间的实施取舍；较宽桌面显示，保存本身不受影响。
3. **待办汇总与动态的下一轮关系**：已确认留到下一轮一起设计，本轮不预设合并、替换或改名。
