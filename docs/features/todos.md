# 我的待办（/todos：跨文件任务汇总 + 任务动态流）

> 本文是「画布任务第二轮」（2026-11-21，spec `docs/superpowers/specs/2026-11-21-task-round2-design.md`）交付的功能逻辑说明；任务模型本身（单总负责人/总进度/逐人子进度）见 `task.md`。

## ① 这是什么

把所有文件里「分配给你的任务」汇总到一个页面直接更新进度。第二轮起，**人员列里的执行人（参与人）也被收录**，并新增跨文件「动态」流。入口：工作台导航「我的待办」（`/todos`，`apps/web/src/pages/TodosPage.tsx`）。

## ② 规则（逐条，标代码出处）

1. **收录范围 = 负责人 ∪ 参与人**：任务是某文件某节点的任务；你是它的总负责人（`owners_csv`）**或**人员列参与人（`task_participant` 表有你的条目）就出现在列表里。同一任务同一人只出现一行，不会重复（行按节点唯一，`apps/server/src/todos/todos.service.ts:120` scopeSql 的 OR EXISTS）。**前提是文件对你可见**（你是文件主人或协作者）且未删除。
2. **参与人索引**：文件保存/装载/待办直改后，服务端从文档重建索引——每个有任务信息的节点，其人员列**每个成员每列一条**落 `task_participant`（同节点多列同人各一行）；人列有条目的节点即使没设负责人也算任务入索引（2026-11-21 裁定：纯参与节点不再隐形，统计任务总数会因此变大，`apps/server/src/todos/task-index.service.ts:45,138`）。
3. **索引存「有效进度」**：索引里的进度/状态/完成日期与画布同源（shared derive `taskProgressOf/taskStatusOf/taskDoneDateOf`）——自动父任务在待办里也显示子任务汇总值（`task-index.service.ts:92`）。
4. **统计卡口径**：全部待办/今日到期/已逾期/7 天内到期/已完成，都按「负责人 ∪ 参与人」圈范围、任务级计数（`todos.service.ts:137` page 的 stats 查询）。
5. **文件 → 画布两级分组**：列表先按文件折叠，文件内再按画布分组（`TodosPage.tsx` byFileCanvas 分组）；没有画布信息的旧行显示「未知画布」——文件在重建器上线后**打开一次即修复**（装载兜底 `rebuildIfStaleInBackground`，`task-index.service.ts:251`）。
6. **角色徽章**：行上显示你在这条任务里的角色——「总负责人」（含双身份：既负责又执行）或「执行人」（`TodoItem.myRole`，双身份只显示总负责人徽章，2026-11-21 裁定）。
7. **行上滑条/勾选 = 任务总进度/完成**：对所有角色一致（2026-11-21 裁定 5）；勾选完成走服务端直改（优先写在线协作文档、无在线会话写落库状态并重建索引，`todos.service.ts:219` patchTask）；自动汇总父任务不能在这里完成/改总进度（两段式提示「请进入文件更新子任务」）。
8. **「我的子进度 %」可点击**：执行人（含双身份）行上显示「我的子进度 N%」，点击弹 9 档选盘（0/13/25/38/50/63/75/88/100），选值后**你在该任务上的全部执行来源一起改**（各人员列条目 + 你是负责人时的负责人子进度，2026-11-21 裁定「全部来源一起改」；`todos.service.ts:239` mySubProgress 分支）。你不是这条任务的负责人/执行人时返回两段式 400。子进度写 100 **不会**完成任务——完成只看任务总进度。
9. **「我的子进度未完成」chip**：今日/所有待办页签上有这个筛选 chip，勾上后只显示「我是执行人之一、我的子进度没拉满、任务未完成」的行（`TodosPage.tsx:304`；已完成页签不出现）。
10. **任务动态（跨文件流）**：第四个页签「动态」显示与你相关的任务变化——我是负责人/参与人的任务，或操作者是我（`todos.service.ts:394` activity：events 表 `task_*` ∩ 可见文件 ∩ payload 含我 id 或操作者是我，倒序 50 条）。行点击打开对应文件（不定位到节点）。事件在**服务端盖章落库**：编辑器内每次用户级任务写成功后客户端发声明，服务端以**连接身份**覆盖操作者、从文档现值取任务文案、拒绝只读连接与伪造 nodeId（`apps/server/src/collab/collab.service.ts:224` handleTaskEventDeclaration）；待办页的直改（完成/重开/进度/我的子进度）由服务端直接记事件（`todos.service.ts:302` recordPatchEvents）；自动父的汇总值变化没有用户级写入，由索引重建时对比补记（操作者按触发重建的最后修改者归属，近似口径，`task-index.service.ts:203`）。
11. **文件内也能看动态**：编辑器工具栏「文档动态」抽屉显示同一批任务事件（`apps/web/src/editor/ActivityPanel.tsx`，task_* 类型渲染动作+任务文案）。
12. **分组 chips 只显示能筛出内容的分组**（2026-11-21 需求方追加）：页签下的分组筛选 chips 按当前列表派生——分组内有任一任务（负责人或参与人落在该分组）才显示，目录里无关的分组不再刷屏；当前选中的分组恒显示（否则无法取消）。派生源 = 页签 + 「我的子进度未完成」过滤之后、分组过滤之前的列表（`apps/web/src/pages/TodosPage.tsx:172` baseItems / `:190` groupOptions）。命中判定 = 负责人 ∪ 参与人任一人在该分组。
13. **参与范围配置（2026-11-21 需求方追加）**：待办页与统计面板页头各有「⚙ 配置」按钮，打开**同一份**每用户配置（`apps/web/src/pages/TodoScopeDialog.tsx`，服务端 `todo_scope_config` 表，跨设备一致）：
    - **默认全关联**：新文件/新任务自动参与，无需任何配置；配置里存的是「排除行」；
    - **两级开关**：文件总开关（关 = 整个文件从待办和统计里消失）+ 展开后的画布级开关（只列**有任务**的画布；无任务画布排除无意义）；
    - **覆盖面**：任务列表、五张统计卡、待办空间聚合/明细/下钻、**动态页签**（被排除文件/画布的任务事件也不出现，2026-11-21 需求方确认跟随）——四处都由服务端按排除行过滤（`todos.service.ts` scopeSql 的 NOT EXISTS + activity 的 NOT EXISTS），列表与数字不会对不上；
    - 配置清单 = 我可见的存活文件全集（含暂无任务的）；画布清单来自任务索引（旧索引行「未知画布」不入画布清单，文件级开关可覆盖）；
    - 开关即改即生效（PUT `/api/todos/scope` 幂等），改动即时刷新当前页面数据。

## ③ 特殊情况

| 场景 | 表现 |
|------|------|
| 任务的文件已被删除/你被移出协作 | 行消失（范围查询 JOIN 存活可见文件） |
| 旧文件从没在新索引下打开过 | 画布显示「未知画布」；打开一次文件自动修复 |
| 待办页断网 | 列表只读（拉取失败空态），直改请求失败 toast 两段式提示 |
| 我的子进度写时任务刚被改动 | 服务端以最新文档为准写；无在线会话走落库直写，两个入口都走 core 校验 |
| 断线期间的编辑器内任务改动 | 不产生动态事件（声明通道断开即丢，已知限制如实登记） |
| 撤销/重做任务字段 | 不产生动态事件（不经声明入口，已知限制） |
| 连续改三次进度 | 动态显示三条（不做同人短时合并，已知限制） |
| 待办页滑条一次拖动到底 | 按 5% 步进逐档提交，动态出现约 20 条进度事件、每次触发索引重建（量级已知，不合并；如需合并请指示） |
| 排除了某文件但它在「未知画布」状态（索引未重建） | 文件级开关照样生效；画布级清单里看不到它，先打开一次文件即可 |
| 配置里关掉文件再打开 | 排除行删除，任务与统计立即恢复（幂等，重复开关无副作用） |
| 分组 chips 当前选中后该分组内容被清空 | 选中分组恒显示（可手动取消），不因内容为空而消失 |
| 统计面板聚合行的人员**无组织挂靠**（无部门/分组） | 名字仍显示 users 表真昵称（目录查不到时回退服务端昵称，不再显示「成员+id尾段」）；部门列显示「未分配」 |
| 统计面板点某人行下钻 | 任务明细池=统计池（可见文件全部任务、全状态）——选任何人行都能看到他的任务；「已完成」状态 chip 由此真正可用（此前明细只含我自己的未完成任务，他人行下钻必空、已完成 chip 恒空） |
| 统计面板「按人员」行的头像 | 有头像（上传/预置）渲染真实头像图片（`report.people`/`byOwner.avatarUrl` 存储键 → avatarSrcOf 直出），无头像回退名字首字色块（2026-11-21 修正：此前恒为名字首字文本块，且首字取自错误的兜底名） |
| 统计面板切「今日/本周/本月」等范围后看任务明细 | 明细池不分时间范围（始终全部可见任务），名单（report.people）也与范围解耦——范围外人员的负责人/参与人列仍解析真名（2026-11-21 需求方实测：「今日」下明细负责人列曾显示「成员+id尾段」，因名单误用按范围过滤的 byOwner 建映射） |
| 伪造操作者/ nodeId 的声明 | 服务端丢弃或盖章覆盖，绝不落客户端声明的操作者 |

## ④ 待需求方确认

- 被排除的文件在待办页/统计面板页头不显示任何「已排除 N 个」角标——如果你希望页面上能一眼看到当前排除了几个文件请指示。
- 双身份（既负责又执行）行上徽章只显示「总负责人」，但「我的子进度 %」仍显示可点——若希望双身份不显示子进度请指示。
- 「动态」行点击=打开文件编辑器（不定位到节点）——若希望点击后自动选中该节点请指示。
- 旧索引行「未知画布」依赖文件被打开一次；如果你希望部署时后台跑一次全量重建消除这个窗口期（代价是部署期长事务）请指示。
