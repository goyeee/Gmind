## 二、信息架构（§1 布局三段式）

**左侧栏**（固定 220px 量级，desktop 恒显）：
- 顶部：Gmind logo
- 导航（testid 契约）：`nav-mine` 我的文件 / `nav-recent` 最近使用 / `nav-starred` 星标收藏 / `nav-collab` 协作空间 / `nav-templates` 模板库 / `nav-trash` 回收站
- 底部：用户卡 `user-card`（头像 + 昵称），点击弹菜单 `user-menu`：账号设置 / 账号管理（仅 super_admin 渲染，沿用旧口径）/ 退出登录

**顶栏**：搜索框（搜索脑图标题，沿用现有 GET /api/search）/ `+ 新建脑图` 主按钮（`quick-create-blank` 同源动作）/ 通知铃 / 头像（与用户卡同一菜单）。

**顶栏退役**：回收站/账号设置/账号管理/退出登录四个旧顶栏按钮 testid 退役（迁入用户菜单）。

## 三、首页与各视图

**首页 = 「我的文件」视图默认落地**，自上而下：
1. 问候语：时段问候（上午好/下午好/晚上好）+ 昵称 + 副文案（静态）
2. 快速创建卡两枚：`quick-create-blank` 空白脑图（即建即跳编辑器）/ `quick-create-template` 从模板创建（跳「模板库」视图）
3. 最近文件卡片流：`file-card`（装饰性缩略图 + 标题 + 相对时间 · 所属（个人/协作）+ 星标钮），协作文件带协作图标；右上「查看全部」→ `nav-recent`

**视图语义**：
- 我的文件：`view=mine` 全量卡片网格
- 最近使用：`view=recent` + 协作文件图标 + 筛选器（全部/个人/协作，客户端过滤）
- 星标收藏：`view=starred` 沿用
- 协作空间：`view=shared`（与外部协作的文件集合，侧栏一级入口）
- 模板库：内置模板画廊——模板卡（缩略图 + 名称 + 简介）→ 点击进预览（大缩略图 + 结构说明）→「使用模板」一键建文档并跳编辑器
- 回收站：沿用现状（TrashPage 不动），仅入口迁入侧栏

**文件卡片操作**：hover 浮出 ⋯ 菜单（重命名 / 复制 / 星标 / 删除——删除仅 owner，沿用 PRD 2.2.1 口径）；**重命名改行内就地编辑**（卡内 input，Enter 提交/Esc 取消），旧 openPrompt 对话框退役。原列表 ··· 菜单的 overflow 裁剪 bug 随列表重做自然消解。

## 四、关键实现口径

- **缩略图 = 装饰性静态图**（不渲染真实文档内容）：按文档主题色生成「色块 root + 三分支」迷你图（与参考图同款装饰图），确定性取色（themeId 哈希取板色）。**docState 不出服务端的契约不破**，无 per-card 拉取开销。
- **模板数据**：core `SEED_TEMPLATES` 扩充为 `TEMPLATE_CATALOG`（每模板：id/名称/简介/结构/docState 工厂），客户端直读（不经服务端新端点）；「使用模板」= POST /files { title, docState: createTemplateDoc(templateId) }（复用 M4 导入落库路径，entry='import' 或新增 'template'——埋点口径实现时定）。
- **协作图标**：卡片上 owner≠me 即协作标（人物小图标）。
- **响应式**：移动端沿用最简（列表单列、侧栏收进抽屉）——本次不做精细化，不劣化即可。
