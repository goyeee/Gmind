# 登录页原型布局修正（2026-11-16）

## 目标

按最新 Figma 原型修正登录页布局：左侧为“顶部标志—中间脑图插画—底部介绍”三段排列，解决插画与标题重叠；右侧表单保持水平、垂直居中，并预留 `4vh` 底部间距。

## 现状与根因

- 当前 `.login-hero-art` 使用 `position: absolute; inset: 0` 铺满左栏，和居中的标题、说明占据同一区域，已在 `1440×900` 页面截图中复现重叠。
- 脑图 `InfiniteMap` 与原型实现一致，问题在承载它的页面布局，不重写脑图算法。
- 右侧 `.login-panel` 已有 flex 居中，只缺原型新增的底部间距。

## 方案比较

- **采用：左侧恢复正常文档流，标志、插画、介绍各占一段；插画区域使用剩余空间并垂直居中。** 直接消除重叠根因，与原型一致。
- 不采用：继续绝对定位插画，再移动标题或节点。不同视口下仍可能重叠。
- 不采用：恢复旧的少量节点插画。用户明确要求按原型布局保留新脑图。

## 约束

- 保留现有浅蓝背景、文案、`InfiniteMap` 插画和四个特点标签。
- 标题按原型在同一行展示“让想法自由生长，连接成图”。
- 不改变登录、注册、忘记密码的内容、交互、testid 或业务逻辑。
- 保留工作区其他未提交改动，不提交、不推送。

## 验收

- `1440×900`、`1024×768` 下，标志、插画、标题和底部介绍没有垂直重叠。
- `1280×800`、`390×844` 下，右侧表单位置符合居中加 `4vh` 底部间距。
- 登录页三视图及既有自动化用例不受影响；实际浏览器截图复核桌面效果。

## 一屏适配补充（2026-11-17，需求方授权直接适配）

- **新问题**：`1280×800` 下页面实际高 818.875px，出现纵向滚动。
- **根因**：外层只有 `min-height: 100vh`，插画仍按宽度取得完整固有高度，把外层撑高；只给插画容器 `min-height: 0` 不足以解决。
- **采用方案**：登录页外层改为 `height: 100vh`，插画容器允许收缩，内部 SVG 等比缩放。不是隐藏滚动条，也不裁切内容；异常小的窗口仍允许内容自然溢出。
- **验收**：`1440×900`、`1280×800`、`1280×720`、`1024×768` 下文档高度等于窗口高度，标志、插画、介绍互不重叠。

## 设计稿与动效还原补充（2026-11-17）

- **需求方指定依据**：Figma `vUSwg7KMXEl4ESF9BdCK5c` 节点 `16:707` 的截图，以及本地原型 `Login.tsx`、`InfiniteMap.tsx`、`ui.tsx`、`index.css`。首次 API 因旧 token 过期返回 403；需求方提供新凭证后已成功读取实际登录节点 `16:708`，凭证未写入项目或文档。
- **静态差异修正**：左栏改为原型的 `1.1fr : 1fr` 比例；补蓝紫背景光晕、Share2 连线标志、四个特点图标、原型介绍文案、2025 版权年。Figma 实读特点与版权文字均为 `12.25px`，介绍最大宽度 `448px`，右侧标题 `28px/28px`；按真实参数实现，不再按默认 Tailwind 尺寸估算。右侧表单逻辑不变。
- **动效根因**：此前复制了 Tailwind 动画类名，真实项目没有 Tailwind，也没有对应 keyframes，因此未播放。
- **采用方案**：保留 `InfiniteMap` 的布局算法和 SVG；将二级及以下连线设为 700ms 淡入，延迟为 `depth × 180ms`；节点同样淡入，延迟为 `100ms + depth × 180ms`。一级连线与中心节点保持原型现状，不额外编造动画。系统要求减少动态效果时禁用动画。
- **验收**：实际浏览器存在并播放上述分阶层动画；设计稿比例与装饰可见；一屏适配和既有登录功能不回退。
