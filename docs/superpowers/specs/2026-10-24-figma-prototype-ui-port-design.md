# Gmind UI 换装第一期：Figma Make 原型样式移植设计

- 日期：2026-10-24
- 状态：已获需求方批准（四问裁定见 §二）
- 原型：`~/Downloads/Gmind脑图表格产品`（Figma Make 导出，React19+Tailwind4+全 mock；仅作视觉规格书，代码零复用）

## 一、背景与目标

需求方用 Figma Make 产出了 Gmind 的全新 UI 原型（脑图+表格产品方向），对样式与交互表达满意，要求落地到真实项目。分两期：

- **第一期（本 spec）**：把原型的页面样式移植到真实项目——「先把页面样式搞过来」；
- **第二期（另行裁定）**：原型中未实现的功能（我的待办/待办空间/表格文件类型/部门分组等）再逐一实现。

原型的编辑器与 Gmind 真实编辑器高度同源（工具栏/协作光标胶囊/画布页签一一对应），第一期的价值在「它在我们真产品之上多画了什么」与整体视觉语言的统一。

## 二、需求方裁定（2026-10-24，四问）

1. **第一期范围**：工作台全侧 + 登录页；编辑器只做令牌对齐不动结构；原型里没有实现载体的功能页（我的待办/待办空间/组织管理部门·分组页签）**不建空壳**，留到功能期。
2. **协作空间**：保留 2026-10-20 裁定「协作空间=协作文件集合」，只换视觉皮，不建空间实体。
3. **登录页**：以 Figma 原型 split-hero 风格为准（design-demos 的 Gmind-Login-v2 设计稿本让位），右侧表单套**现有真实登录方式**（手机/邮箱验证码，微信扫码占位）。
4. **原型没画的真实功能入口**：全部保留（导入 XMind/账号设置/通知下拉/成员面板/版本·主题·结构·导出面板/任务表格），用原型视觉语言重新串场，不删不藏。

## 三、技术路线

**手移植设计令牌进现有 CSS 架构**（`styles.css` + 各页 `*.css`），零新依赖。

- 否决引入 Tailwind：范式冲突、全量 className 重写会大面积扰动 e2e testid/DOM 契约；
- 否决复用原型代码：React19/Tailwind4/全 mock 数据，逻辑与数据不可用；
- 原型源文件（`src/index.css`、`components/*.tsx`）作为逐页视觉规格对照。

**硬约束**：

- 所有 `data-testid` 保留 → 目标 e2e 断言零改动、门禁五件套全绿；
- engine 布局金样不碰（纯 CSS/页面层变更，engine 一行不改；编辑器令牌对齐只动页面 CSS 与画布背景一行）；
- 少量按 CSS 类断言的 e2e（如 `.trash-list li`）保留类名骨架，只改样式属性。

## 五、页面改造清单

### 5.1 登录页（LoginPage + login.css 重写）

- **布局**：split 双栏。左 hero（约 55%，浅蓝渐变 `brand-soft→白`）：Gmind logo、CSS 绘制的脑图节点/连线装饰（中心主题胶囊+四散子题胶囊+贝塞尔连线，仿原型）、大标语「让想法自由生长，连接成图」（"连接成图" brand 色）、一句话简介、三特性 chip（实时协作/无限画布/多结构切换——皆为真实能力）、页脚版权。右侧白底：表单卡。
- **表单**：保留现有真实登录能力与文案——方式 tabs（手机号/邮箱验证码、微信扫码占位「模拟微信扫码登录」现有按钮语义不变）、验证码 123456 提示、登录钮 brand 实色。底部「登录即代表同意《服务协议》与《隐私政策》」样式化。
- **不变**：doLogin 全部逻辑、token 存储、跳转；auth/error-copy 等 spec 按 placeholder/文案定位的选择器全保留。

### 5.2 外壳 WorkspaceShell

- 侧栏：图标+文字项，active=brand-soft 圆角块+brand 字（现为描边块则改）；回收站沉底分隔（已近，微调）；底部用户卡（头像+昵称+手机号，菜单入口不变）。
- 顶栏：搜索胶囊（canvas 底、聚焦白底+brand 30% ring）、「+ 新建」brand 实色按钮（渐变可选平替纯色）、铃铛去盒化维持。
- 超管「组织管理」不进侧栏（原型有；本期 IA 不动，入口仍在用户菜单——功能期随组织管理三页签一起挪）。

### 5.3 首页（WorkspacePage recent 视图）

- 问候语+副标（现有）套新字阶；
- **快速创建**：三张卡——「新建脑图」（brand 实底高亮卡，白字，原型同款）/「从模板创建」/「导入 XMind」（现有顶栏导入入口保留，卡为直达shortcut，testid 新增不破坏既有）。「新建表格」卡不做（功能期）。
- **最近文件**：横排卡行+右侧「查看全部 →」；卡片元数据=类型徽标「脑图」+星标+真实缩略图（我们领先原型的装饰图，保留真图）+标题+操作者头像+「N 节点 · 相对时间」。
- **推荐模板**：取 TEMPLATE_CATALOG 前 3 张模板卡，尾随「更多模板 →」跳模板库。
- 我的文件网格：现结构+新卡皮（§5.4 卡片规范）。

### 5.4 文件视图换皮（我的文件/星标收藏/协作空间/回收站行卡）

- 页头规范：H1+计数副标（「共 N 个文件」）+右上主操作钮；
- 筛选 chips（全部/个人/协作）换胶囊皮（active=brand-soft/brand 字）；「脑图/表格」类型页签不做（无表格类型）；
- 文件卡：shadow-card 默认、hover 浮起、圆角 10、类型徽标左上、星标右上、⋯菜单浮层换 shadow-pop+圆角 10；
- 协作空间视图：页头用原型「空间文件」区标题语言（副标「和团队在同一张画布上思考」可借），**数据与 IA 仍为协作文件集合**。

### 5.5 模板中心（Templates 视图）

- **hero 精选横幅**：brand 渐变底、左文案（「本周精选」徽标+模板名+blurb+「使用此模板 →」白底钮+「预览」描边钮）、右内嵌大预览卡（现有预览弹层复用）；
- **分类 chips**：`WorkspaceTemplate` 增可选 `category?: string`（会议/项目/团队/学习/个人，轻数据变更）+「全部」chip；无值的模板归「全部」；
- 画廊卡：blurb+分类角标；**「N 万人使用」假数据与「热门」徽标本期都不做**。

### 5.6 账号管理（AdminUsersPage）

- 页头：H1+「仅管理员可见」徽标位+搜索框（已有）+「+ 新增账号」brand 钮；
- 表格：新皮（表头灰字、行 hover、状态/角色徽标列、分页器样式对齐）；部门/分组列**不做**。

### 5.7 账号设置 / 回收站

- 外壳内令牌对齐：设置表单控件（输入/按钮/危险区）统一新控件皮；回收站行卡 hover 浮起维持、按钮新皮。

### 5.8 编辑器（令牌对齐，单独提交）

- 工具栏/右列面板/浮层菜单：圆角、阴影两级、描边色、字重对齐令牌；
- **画布点阵背景**：`radial-gradient` 点阵叠主题 canvasBackground 打底（浅色主题启用；暗色主题保持纯色）——仅改 EditorPage 画布背景赋值一处 + CSS，engine 零变更；
- 结构、按钮组、交互、键盘全不动；此批次独立 commit 便于回退。

## 七、验收标准

1. 门禁五件套全绿：`pnpm lint && pnpm typecheck && pnpm test && pnpm --filter @gmind/server test:e2e && WEB_PORT=5174 API_ORIGIN=http://localhost:3001 pnpm --filter @gmind/web e2e`（web 侧 `--workers=1`）；e2e 断言目标零改动（允许因视觉所致的截图/样式类基线更新，逐条登记）。
